# Debian Bullseye 11 LXC base system configuration

*Created on 2021-11-21. Last updated on 2022-10-10.*

Upon installation of a Linux Container with Debian Bullseye 11 from the list of [available images provided by Proxmox](https://pve.proxmox.com/wiki/Linux_Container#pct_container_images), we are going to follow these configuration steps.

## DNS

During the creation process, in the *DNS* tab of the wizard, set the DNS values as follows if, and only if, the \[\[Configuration_of_PowerDNS_44_on_Debian_11_Bullseye\|PowerDNS Server\]\] with the local zones has already been installed:

-   DNS domain: `andromedant.com`
-   DNS server: `192.168.0.253 192.168.0.254`

Also, when appropriate, add the host to the internal DNS server. On the `pdns1` host, execute the following commands:

    pdnsutil add-record andromedant.com lxc1 A 192.168.0.100
    pdnsutil increase-serial andromedant.com
    pdns_control notify andromedant.com

And restart the server:

    systemctl restart pdns-recursor

## Locale

The locales available by default can be checked with the following command:

    ~# localectl list-locales
    C.UTF-8

Install and set the default system locale to `en_US`:

    localectl set-locale en_US.UTF-8

Later, if you need to re-generate the installed locales you would use the following command:

    ~# locale-gen
    Generating locales (this might take a while)...
      en_US.UTF-8... done
    Generation complete.

Reboot.

## Debian packages mirrors and proxy

Configure the APT proxy by creating the file `/etc/apt/apt.conf.d/00aptproxy` with the following configuration:

    Acquire::http::Proxy "http://apt.andromedant.com:3142";

Configure the mirror to get packages from in the `/etc/apt/sources.list` file:

    # Packages and security updates from the Hetzner Debian mirror
    deb http://mirror.hetzner.com/debian/packages bullseye main contrib non-free
    deb http://mirror.hetzner.com/debian/packages bullseye-updates main contrib non-free
    deb http://mirror.hetzner.com/debian/packages bullseye-backports main contrib non-free
    deb http://mirror.hetzner.com/debian/security bullseye-security main contrib non-free

    # Debian mirror
    deb http://ftp.de.debian.org/debian bullseye main contrib non-free
    deb http://ftp.de.debian.org/debian bullseye-updates main contrib non-free
    deb http://ftp.de.debian.org/debian bullseye-backports main contrib non-free
    deb http://security.debian.org/debian-security bullseye-security main contrib non-free

Upgrade existing packages to the latest version:

    apt update
    apt list --upgradable
    apt full-upgrade

Reboot.

## HTTP proxy

For those containers without a public IP address, configure the HTTP proxy by creating the file `/etc/profile.d/proxy.sh` with the following content:

    URL="proxy.andromedant.com:8080" 

    http_proxy=http://$URL
    https_proxy=http://$URL
    ftp_proxy=http://$URL
    HTTP_PROXY=http://$URL
    HTTPS_PROXY=http://$URL
    FTP_PROXY=http://$URL

    export HTTP_PROXY HTTPS_PROXY FTP_PROXY http_proxy https_proxy ftp_proxy

And make the file executable:

    chmod +x /etc/profile.d/proxy.sh

Reboot.

## Utilities

Install some useful packages:

    apt install ccze dnsutils lsb-release nmap net-tools tree vim

## Default editor

By default both *Nano* and *Vim Tiny* are installed, but the former is the default one. *Vim Tiny* lives as `/usr/bin/vim.tiny` and, if we installed the `vim` package, *Vim* lives as `/usr/bin/vim.basic`.

We can change the default editor with the `select-editor` command, or we can create the file `~/.selected_editor` and add the following content in it:

    # Generated by /usr/bin/select-editor
    SELECTED_EDITOR="/usr/bin/vim.basic"

Alternatively, the following command should also work:

    update-alternatives --set editor /usr/bin/vim.basic

If we want to be shown the list of available editors and select the default one manually we can use this command:

    update-alternatives --config editor

### Vim configuration

Optionally, create the file `~/.vimrc` with the following content:

    " Load defaults from /etc/vim/vimrc
    runtime defaults.vim

    " On pressing tab, insert 2 spaces
    " Show existing tabs with 2 spaces width
    " When indenting with '>', use 2 spaces width
    set tabstop=2 softtabstop=0 expandtab shiftwidth=2 smarttab
    set pastetoggle=<F3>

To avoid autoindenting when pasting code into the console, use the following command:

    :set paste

To go back to normal mode after pasting is complete, use this command:

    :set nopaste

To switch from the two modes easily, map a key to the toggle action:

    set pastetoggle=<F3>

## *Systemd* journal logs

The *systemd* journal is *systemd*’s own logging system, equivalent to what the *syslog* was in the *init system*. It collects and stores kernel logging data, system log messages, and standard output and error for various *systemd* services.

Log files are written in the `/var/log/journal` directory. *Systemd* provides `journalctl`, a command line tool that allow interaction with the journal logs: read logs, monitor logs in real time, filter logs based on time, service, severity and other parameters.

Use the following command to list the existing log file entries in reverse order (most recent first):

    journalctl -r

Use the following command to check how much space the log files are taking in the disk:

    journalctl --disk-usage

Edit the configuration file `/etc/systemd/journald.conf` to set the maximum disk space used for the container so that it does not grow too big:

    SystemMaxUse=200M

Restart *journald* for the changes to take effect:

    systemctl restart systemd-journald

### Manual rotation and clearing of old files

Should you need to manually rotate the log files, use the following command to mark the current journal log file as archived and create a new one:

    journalctl --rotate

Once rotated, you can manually clear old journal files in a number of ways, depending on the criteria that interests you.

To delete all entries older than a number of days, use this command:

    journalctl --vacuum-time=3d

To shrink the total disk space to a certain amount, deleting all old files until necessary, use this command:

    journalctl --vacuum-size=200M

You can specify the size in GB with G, MB with M and KB with K.

To limit the total amount of log files, removing the older archive log files and leaving only the specified number, use the following command:

    journalctl --vacuum-files=7

### Useful commands

Show all messages from this boot:

    journalctl -b

Show all messages from the previous boot:

    journalctl -b -1

List all available boots:

    journalctl --list-boots

Show all messages from date and (optional) time:

    journalctl --since="2022-01-21 20:17:16"

Show all messages since 20 minutes ago:

    journalctl --since "20 min ago"

Follow new messages:

    journalctl -f

Show all messages by a specific executable:

    journalctl /usr/lib/postfix/sbin/master

Show all messages by a specific unit:

    journalctl -u postgresql@13-main.service

Show only error, critical and alert priority messages:

    journalctl -p err..alert
