Here you will find a number of articles that relate to the installation, configuration and operation of [Grafana Labs](https://grafana.com/) open-source software products. Grafana Labs develops an open-source observability platform centered around Grafana for visualization, Prometheus for metrics collection, Loki for log aggregation, Promtail as a log collector for Loki, and Grafana Alerting for unified alerting across metrics and logs.

* Grafana is an open-source platform for visualizing and analyzing time-series data.
* Prometheus is an open-source monitoring and alerting toolkit for collecting metrics.
* Loki is a horizontally scalable, multi-tenant log aggregation system that indexes logs via labels.
* Grafana Alerting enables unified alert creation and management across metrics, logs, and traces.
* Promtail is a log collector that ships logs to Loki with labeling and filtering capabilities.
