The automation category covers all articles related to the creation and implementation of automated processes and software in place of time-consuming manual activities.

These articles will mostly talk about software provisioning, configuration management, and application deployment functionality using Ansible, an open-source, cross-platform resource provisioning tool, in the context of a Proxmox VE cluster.
