---
title: "Domain Name System"
date: 2024-09-16
---

El Domain Name System (DNS), la guia telefònica d'Internet, és un servei de noms jeràrquic i distribuït que proporciona un sistema de noms per a ordinadors, serveis i altres recursos a Internet o altres xarxes de Protocol d'Internet (IP).

Principalment, tradueix noms de domini fàcilment memoritzables a les adreces IP numèriques necessàries per localitzar i identificar serveis i dispositius informàtics amb els protocols de xarxa subjacents.

En el cas del World Wide Web, els humans accedeixen a la informació en línia a través de noms de domini, com calabruix.es. Els navegadors web interactuen mitjançant adreces de Protocol d'Internet (IP). El DNS tradueix noms de domini a adreces IP perquè els navegadors puguin carregar recursos d'Internet.
