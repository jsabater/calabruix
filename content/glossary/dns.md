---
title: "Domain Name System"
date: 2024-09-16
---

The Domain Name System (DNS), the phonebook of the Internet, is a hierarchical and distributed name service that provides a naming system for computers, services, and other resources on the Internet or other Internet Protocol (IP) networks.

Most prominently, it translates readily memorized domain names to the numerical IP addresses needed for locating and identifying computer services and devices with the underlying network protocols.

In case of the World Wide Web, humans access information online through domain names, like calabruix.es. Web browsers interact through Internet Protocol (IP) addresses. DNS translates domain names to IP addresses so browsers can load Internet resources.
