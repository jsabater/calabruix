---
title: "Fourth Extended Filesystem"
date: 2025-07-04
---

Fourth Extended Filesystem (EXT4) is a widely used journaling file system for Linux. It is the successor to EXT3 and it is the default file system for many Linux distributions and is known for its stability and performance.

Key features include journaling, support for large files and volumes, extents for efficient file management, delayed allocation for improved performance, backward compatibility with EXT3 and EXT2 file systems and online defragmentation capabilities.
